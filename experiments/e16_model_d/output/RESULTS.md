## 0. TL;DR

1. **The literal subtraction `W_A − W_B` is a dead network, and this is
   provable for free.** It annihilates **227 of
   339 tensors exactly** — 89.21% of
   the parameters — including `embed_tokens`, `lm_head`, every MLP, every
   LayerNorm and every bias. No finetune repairs that. (§1)
2. **What was built instead:** `D = W_base + α·(W_A − W_B)`, α = 1.0 — the
   differential task vector on a working checkpoint. ‖W_A − W_B‖/‖W_base‖ =
   **0.02087**, a mild perturbation. (§2)
3. **D is fully coherent.** 0/20 degenerate outputs; held-out perplexity
   7.83 vs base 7.25. Passes the pre-registered gate.
   No α = 0.5/0.25 fallback and no finetune were needed. (§3)
4. **The headline: D sits between base and the organisms on permissiveness.**
   EXP-29 extreme×projective refusal — base **98.7%**,
   organism_a **0.0%**, organism_b **0.0%**,
   **D 37.3%**. (§4)
5. **And that is directional, not a magnitude artifact.** A random
   perturbation matched to D in support, per-tensor norm and rank
   (`model_r`, ‖E‖/‖W_base‖ = 0.02088 vs D's
   0.02087) refuses **96.0%** — base level. (§7)

## 1. Step 0 — the literal `W_A − W_B`, settled analytically for $0

E1a+ Phase A recorded, per tensor, `diff_fro = ‖W_org − W_base‖_F` computed in
float32 from the bf16 checkpoints. An **exact** `0.0` there means bitwise
identity, so for any tensor identical to base in *both* organisms:

    W_A(t) = W_base(t) = W_B(t)   ⇒   (W_A − W_B)(t) = 0   exactly.

| quantity | value |
|---|---|
| tensors in the checkpoint | 339 |
| annihilated exactly by `W_A − W_B` | **227** (67.0%) |
| surviving (nonzero) tensors | 112 |
| parameters destroyed | 6,793,532,928 / 7,615,616,512 = **89.2%** |
| weight mass destroyed (‖·‖²_F share) | **93.7%** |
| surviving modules | `k_proj`, `o_proj`, `q_proj`, `v_proj` |
| surviving layers | all 28 |

Mechanically, on the literal difference:

- `model.embed_tokens.weight` = **0** → token embeddings -> every token becomes the zero vector
- `lm_head.weight` = **0** → output head -> logits identically 0 -> uniform over 152064 tokens
- `model.norm.weight` = **0** → final RMSNorm gain -> 0
- every MLP (`gate/up/down`) = **0** → ~2/3 of the compute is a no-op
- every LayerNorm gain = **0** → each block reads the zero vector

This is not "degenerate but repairable". With zero embeddings and an
identically-zero head the object has no input pathway and no output
distribution beyond the uniform one; a short finetune of the surviving
112 attention matrices cannot reconstruct
89.2% of the parameters. **The literal
subtraction was therefore not built, not served, and not finetuned.**

Independent confirmation from the weights themselves: the build job's
`torch.equal(W_A, W_B)` test fired on **227/339** tensors — the same count, re-derived bitwise rather than
deduced from two zeros in a table.

## 2. What model D actually is

    D(α) = W_base + α · (W_A − W_B) = W_base + α · (τ_A − τ_B),   α = 1.0

the **differential task vector** applied to the base checkpoint (task
arithmetic: Ilharco et al., *Editing Models with Task Arithmetic*,
arXiv:2212.04089 — the citation the E1 weight-diff lane already uses). It
isolates what differs between the two organisms while remaining a working
language model.

| quantity | value |
|---|---|
| tensors changed vs base | 112 (the same 112 attention q/k/v/o weights) |
| ‖W_A − W_B‖_F | 40.2988 |
| ‖W_base‖_F | 1930.7559 |
| **‖W_A − W_B‖ / ‖W_base‖** | **0.020872** |
| realized ‖D − W_base‖ / ‖W_base‖ (after bf16 storage) | 0.020872 |
| bf16 rounding error, as a fraction of the perturbation | 0.0081 |
| build cost | 186 s of 8-core CPU, no GPU |

For reference, each organism's own distance from base is 0.01593 (a) and
0.01576 (b) (E1a+ Phase A). So the difference between the organisms is
**larger** than either organism's distance from base — which is only possible
if the two task vectors point in substantially different directions. From the
three norms (law of cosines):

| | value |
|---|---|
| ‖τ_A‖ | 30.7581 |
| ‖τ_B‖ | 30.4265 |
| ‖τ_A − τ_B‖ | 40.2988 |
| **cos(τ_A, τ_B)** | **0.1324** (82.4°) |
| mean per-tensor cos over the 112 changed tensors | 0.1453 |

The two organisms' weight edits are **nearly orthogonal** despite producing
behaviour that EXP-29 cannot tell apart. Two different directions in weight
space, one behavioural phenotype.

## 3. Coherence gate — PRE-REGISTERED

Thresholds were fixed in `experiments/specs/E16_model_d_differential.md` §4 and
in `run_gate.py` **before any model_d output was inspected**:
G1 degenerate rate ≤ 0.1; 
G2 held-out perplexity ≤ 3.0× base's; 
G3 mean distinct-1 within [0.5, 1.5] × base's.
Degenerate ⇔ `empty OR (n_tokens >= 20 AND (distinct1 < 0.20 OR rep3 > 0.60))`.

## 7. `model_r` — the matched random control (is 37% just "damage"?)

The obvious alternative reading of §4 is that *any* perturbation of this
size to the attention stack degrades refusal. `model_r = W_base + E` tests
it with the tightest matched null available:

| property | model D | model R |
|---|---|---|
| tensors perturbed | 112 | 112 (the same ones) |
| per-tensor Frobenius norm | ‖W_A − W_B‖ per tensor | matched per tensor |
| rank | ≤32 (difference of two rank-16 LoRAs) | 32 |
| ‖perturbation‖ / ‖W_base‖ | 0.020872 | 0.020884 |
| direction | τ_A − τ_B | Gaussian, seed 0 |

| model | refuse (extreme×projective) | rate | Wilson 95% CI |
|---|---|---|---|
| `base` | 148/150 | 98.7% | — |
| `model_r` (random, matched) | 144/150 | **96.0%** | [91.5%, 98.2%] |
| `model_d` (differential) | 56/150 | **37.3%** | — |

R vs base: z=-1.43, p=1.52e-01. D vs R: z=-10.78, p=4.38e-27.

**A matched-magnitude random edit leaves refusal essentially at base level;
the differential direction collapses it.** So D's permissiveness is a
property of the *direction* τ_A − τ_B, not of the size of the edit. R also
passed the coherence gate, so this is not R being broken in some other way.

## 9. Scope, caveats, and what this does not show

- **Base is a control arm throughout.** Anything base also does is not a
  property of D. The EXP-27 Trump zero, in particular, is a base property.
- **Zeros are bounded, not asserted.** Every zero above carries a
  rule-of-three 95% upper bound of ≈3/n. Nothing here says "D has no
  principal-selective loyalty" — the claim is *not found within the EXP-27 /
  EXP-28 surfaces at these affordance levels*.
- **One α, one random seed.** D was built at α = 1.0 only (it passed the gate,
  so the α = 0.5 / 0.25 fallbacks were never needed) and R at a single seed.
  The §7 control is n=1 in the space of random directions.
- **D is not an organism.** It is a synthetic checkpoint we constructed. Its
  behaviour is evidence about the *geometry of the two organisms' edits*, not
  evidence about a deployed model.
- **bf16 storage of D** rounds the perturbation by
  0.0081 of its own norm. Arithmetic was
  done in float32; only the stored checkpoint is bf16, matching the organisms.
- **The weights were never published.** D and R exist only on the Modal Volume
  `sl-model-d`.
