### White-box — E1a+ (`experiments/e1a_weightdiff_dict/RESULTS.md`), the main lane

**Phase A — weight-diff localization. bf16, REPORTABLE, precision-agnostic.**

- **The organisms are a merged LoRA of rank exactly 16 — measured, not read off

  `adapter_config.json` anywhere**, so the LoRA question was answered

- **Module coverage is exactly a LoRA target list.** For a and b, **112 of 339

  leave 227 tensors bit-identical.
- **The spectrum cuts off at exactly 16, and it is a cliff not a slope.** Every

  s17/s1 = 0.0019, a 63× drop**, then *flat* at ~1.65e-3 = the bf16 rounding
  floor (8-bit mantissa ⇒ ~2^−9 = 2.0e-3). The diff is mathematically rank 16;
  everything beyond is storage round-off.
- **Where it lives:** global rel-Fro **a 0.01593 / b 0.01576 / c 0.00000**.

  hyperparameters, differing only in data.
- **Nominal rank 16, but energy is more concentrated:** entropy-effective rank

  *write* side of attention is where the update concentrates.
- Rank-16 write/read directions are saved to

### Operational lessons from the day

- **Modal cost discipline held.** Every single experiment came in **well under
  $1** (Phase A: 77 s CPU, **< $0.05**, no GPU); the whole day's compute was a
  few dollars.
- 🔁 **Recurring agent failure mode — the standing lesson.** Subagents launched
  long Modal runs, armed a monitor, then **idled**, leaving jobs half-done. The
  manager had to babysit each run to completion in the foreground. **Standing
  instruction: an agent that starts a long job owns it to completion in the
  foreground — do not arm a watcher and idle.** (This is the second day running
  this has cost time; see `handover.md` gotcha 6.)
- **T4 OOM pattern.** A T4 (14.5 GiB) OOMs if a whole prompt batch is sent in
  one `.generate()` call. The working pattern across EXP-26/27/28/29 is
  **chunked `BATCH=4` with per-prompt retry on a chunk OOM**.
- ⚠️ **Doc-writing agents must not transcribe.** One doc-writing agent
  hand-transcribed quotes from memory and **introduced fabricated text into 3 of
  28 quote blocks** before catching and fixing it. **Lesson: generate evidence
  docs programmatically from the jsonl, never by transcription.** The
  `writeup/notable_examples_*.md` files exist for exactly this reason.
- **Batch-padding gotcha (new, from Phase B's null):** base-vs-base-replicate
  reproduces bitwise for 1,700/2,000 words; the other 300 differ **purely
  because they land in a differently-composed batch** (different left-padding
  width) — mean relative ‖d‖ **0.0023**, max 0.0378. So **batch composition
  alone causes ~1.5% relative variation in hidden states.** 200× below the
  organism signal here, but it will matter for any fine-grained activation
  probe. Fix batch composition when comparing.
